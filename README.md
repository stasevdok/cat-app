# Кошки

Простой учебный проект на Next.js с App Router. На главной странице можно выбрать породу, открыть галерею и поставить лайк.

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Как подключить GitHub

1. Создайте на GitHub пустой репозиторий без README, `.gitignore` и лицензии.
2. Скопируйте URL репозитория.
3. Выполните команды:

```bash
git branch -M main
git remote add origin ВАШ_URL_РЕПОЗИТОРИЯ
git push -u origin main
```
